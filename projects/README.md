## 如何添加新项目

1. 在本目录下新建子目录，名字用英文短横线，如 `my-tools`
2. 子目录里必须有 `README.md`，写清楚：
   - 这个项目是干什么的
   - 怎么运行(依赖、命令)
   - 当前进度
3. 回到本文件，在上方索引表登记一行

## 建议的项目目录结构

```
projects/
└── my-project/
    ├── README.md        # 必备：说明文档
    ├── src/             # 源代码
    ├── requirements.txt # Python 依赖清单
    └── .gitignore       # 忽略规则(可参考根目录的)
```
