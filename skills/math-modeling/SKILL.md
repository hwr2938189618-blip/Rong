# 数学建模竞赛全流程

## 全局流程

```
赛题与附件解析 → 数据审计 → 题型选型与防错 → 经典基线 + 创新模型
→ MATLAB/Python 求解 → 验证与消融 → 敏感性分析 → 论文（Typst/LaTeX）→ PDF 逐页验收
```

## 各阶段要点

### 1. 赛题与附件解析

- 把附件**全部**列出来（表、图、说明文档），别只看数据文件
- 明确：要求解什么？输出什么形式？有没有隐含约束？
- 记录每一问的**评分指向**（评委在意的是"你有没有回答那一问"）

### 2. 数据审计（决定成败，别跳过）

- 缺失值、异常值、重复行、量纲不一致
- 时间字段是否连续、有没有时区/格式错位
- 数据量级与假设是否匹配（如"人口按正态分布"这类假设要慎用）

### 3. 题型选型与防错

- 先判断题型：评价类 / 预测类 / 优化类 / 机理类 / 统计推断类
- **防错清单**：单位、边界条件、初值、约束是否漏写、模型假设是否与题设冲突
- 选模型宁简勿炫：能解释的基线模型 + 一个有机的创新点，好过堆砌花哨模型

### 4. 基线 + 创新

- **基线**：经典方法（回归、时间序列、线性规划、微分方程、聚类…），必须跑通
- **创新**：在基线之上改进（改目标函数、引入约束、组合模型），并说明"为什么这么改"

### 5. 求解

- MATLAB 或 Python（本机 Python 可用，绝对路径见 `windows-shell-workarounds` 技能）
- 求解脚本要**可复现**：固定随机种子、记录参数、输出中间结果

### 6. 验证与消融

- 交叉验证 / 留出集 / 与已知结果对齐
- **消融实验**：去掉你的创新点，指标掉多少？掉不动说明创新无效

### 7. 敏感性分析

- 关键参数 ±10% / ±20%，看结论是否稳健
- 稳健性不足要在论文里**主动说明**，别藏

### 8. 论文（Typst / LaTeX 双引擎）

- 结构：摘要 → 问题重述 → 模型假设 → 符号说明 → 模型建立与求解 → 检验与敏感性 → 模型评价与推广
- **摘要决定第一印象**：结论、方法、创新点都要在摘要里出现
- Typst 上手快，LaTeX 模板多；两者按赛题模板要求选

### 9. PDF 逐页验收

- 编译后**逐页看**：公式有没有溢出、图有没有被截、表格有没有串页、参考文献是否完整
- 页数、格式是否满足赛题硬性要求

## 交付习惯

- 结论先行，把关键路径、命令、改动文件点名说清
- 所有代码与数据可复现，落文件不只留在对话里
