# [ZCode] 套餐免费额度实测（zai-start-plan）

> **日期**: 2026-11-07
> **标签**: #zcode #套餐 #额度
> **状态**: 🟢 已整理

## 我要解决什么问题

主人问「每日多少免费 token」。网上搜索结果说「ZCode 3.0 每天可达 300 万 token 免费额度」，需要核实这个数字是否属实、是不是长期有效。

## 核心概念

本机 ZCode 登录的是 `account:zai-start-plan`（会员套餐，非 coding plan）。经查官方文档（zcode.z.ai/cn/docs/configuration）：

| 项目 | 事实 |
|---|---|
| 每日免费额度 | **仅新用户前 5 天**体验期发放，过期失效，**不是长期每日都有** |
| 每日额度明细 | 共 800 万 token/天：GLM-5.3 为 300 万/天，GLM-5.3-Flash 为 500 万/天 |
| 付费套餐 | GLM Coding Plan（Lite/Pro/Max），按积分计，含每 5 小时周期限额 + 每周限额，Pro/Max 为 Lite 的 6×/14× |
| 额度用尽 | 等下一个 5 小时周期恢复，不消耗账户其他资源包；另有「额度重置卡」机制 |

⚠️ 修正：网络报道的「每天 300 万免费」是把「体验期内 GLM-5.3 每天 300 万」误传成了长期每日免费。实际只有前 5 天，且总额度是 800 万/天（含 Flash）。

最准的查法：登录 z.ai/subscribe 看账户实际额度显示。

## 踩坑记录

| 问题 | 原因 | 解决 |
|---|---|---|
| 网搜「每天 300 万免费 token」与官方文档对不上 | 二手报道漏掉「仅前 5 天」和「含 Flash 共 800 万」两个关键条件 | 以官方文档为准，引用时标注边界 |
| 想从本机查账户额度 | ZCode 桌面端登录态内部管理，`~/.zcode/cli/config.json`、`%APPDATA%/ZCode` 里都没有可用的 API 凭据 | 无法本地查询额度，只能看官方订阅页或等额度用尽的提示 |
