# 浏览器游戏的无头验证与平衡模拟

> **日期**: 2026-11-27
> **标签**: #游戏开发 #自动化测试 #Node #Chrome #数值平衡
> **状态**: 🟢 已整理

## 我要解决什么问题

做一款纯前端小游戏（[projects/aether-echo](../projects/aether-echo/)《星渊回响》），但本机没有 `node`、没有 npm，也不打算靠人手反复点着测。需要同时解决三件事：

1. **逻辑正确**：完整一局 10 分钟不崩、升级/进化/结算流程都能走通；
2. **数值平衡**：新手用普通构筑能不能活到 3 分钟、5 分钟、10 分钟，BOSS 血量是否合理；
3. **界面可信**：至少要看得到真实浏览器里的画面，而不是"应该没问题"。

结论：用 **Electron 自带的 Node 跑真实游戏代码**做无头模拟，用 **Chrome DevTools Protocol** 做真实浏览器测试与截图，数值只改 `data.js` 一张表。

## 核心概念

### 1. Electron 就是 Node

DSH 桌面端是 Electron 应用，设置环境变量后同一个 exe 就是 Node：

```powershell
$env:ELECTRON_RUN_AS_NODE=1
& "D:\DSH-Desktop\DSH Desktop.exe" -e "console.log(process.version)"
```

但它是 **GUI 子系统**，`console.log` 抓不到。所有结果必须 **写文件** 再读，别指望 stdout。

### 2. 用桩跑真实代码

游戏脚本都是普通 classic script，按顺序 `vm.runInThisContext` 加载即可；提供最小 `window` / `document` / `localStorage` / Canvas 2D 桩，然后直接调 `AE.Game.step(1/60)`，完全绕过渲染与 rAF：

```js
globalThis.window = globalThis;
globalThis.document = {
  getElementById: () => null,
  createElement: () => makeCanvas(),
  addEventListener: () => {}
};
for (const f of files) vm.runInThisContext(fs.readFileSync(f, 'utf8'), { filename: f });
AE.Game.init(makeCanvas());
AE.Game.startRun('echo');
for (let i = 0; i < 3600; i++) AE.Game.step(1 / 60);
```

Canvas 桩用 `Proxy` 吞掉所有绘图方法，`createLinearGradient` 返回带 `addColorStop` 的假对象即可；这样同一份 `draw()` 代码也能跑，能抓到 `ctx.xxx is not a function` 之类的错误。

### 3. 机器人 + 指标

机器人负责：远离敌人、躲子弹、吃经验、对 BOSS 保持输出距离、血量低时吃治疗、卡 CD 闪避。每 10 秒记录一次：时间、等级、HP、击杀、DPS、存活敌人数、BOSS 血量、武器/被动。**看时间线比看单局结果有用**。

### 4. 木桩 DPS 台

单武器、固定距离、锁定一个不还手的木桩，跑 20 秒量真实 DPS。注意：子弹的击退会把木桩推远，实测值会莫名其妙只有设计值的三分之一，必须每帧把它钉回原位。

### 5. CDP 截图与冒烟测试

Chrome 的 `--headless --screenshot` 在页面持续调度 rAF 时可能一直不结束；改用 CDP 主动控制：

```js
const ws = new WebSocket(page.webSocketDebuggerUrl);
// Runtime.evaluate 驱动状态；Page.captureScreenshot 拿 base64 PNG
const shot = await send('Page.captureScreenshot', { format: 'png' });
fs.writeFileSync(out, Buffer.from(shot.result.data, 'base64'));
```

Node 24 自带全局 `WebSocket` 与 `fetch`，不用装 `ws`。通过 `Runtime.exceptionThrown` 与 `Runtime.consoleAPICalled(type=error)` 还能顺手抓真实浏览器里的报错。

## 示例代码

最小 Canvas 桩：

```js
function makeCtx(canvas) {
  const grad = { addColorStop() {} };
  return new Proxy({ canvas, measureText: () => ({ width: 24 }),
    createLinearGradient: () => grad, createRadialGradient: () => grad }, {
    get: (t, k) => (k in t ? t[k] : () => {}),
    set: (t, k, v) => ((t[k] = v), true)
  });
}
```

模拟主循环 + 自动选卡：

```js
for (let step = 0; step < maxSteps; step++) {
  if (G.state === 'levelup') { chooseBestUpgrade(); continue; }
  if (G.state !== 'playing') break;
  botMove();
  AE.Game.step(1 / 60);
  if (step % 600 === 0) recordTimeline();
}
```

## 踩坑记录

| 问题 | 原因 | 解决 |
|---|---|---|
| `node` 命令不存在 | 本机只有 Electron 内置运行时 | `ELECTRON_RUN_AS_NODE=1` 调 DSH Desktop.exe；输出写文件而不是 stdout |
| 用 PowerShell 批量替换源码后中文全变乱码、还丢了换行 | PS 5.1 的 `Get-Content` 按 ANSI(936) 解码 UTF-8，`Set-Content` 再按 UTF-8 写回，属于二次破坏 | 源码只用文件编辑工具改；非要用 PS 就用 .NET `ReadAllText/WriteAllText` + `UTF8Encoding(false)`，且换行符要按实际文件匹配 |
| Chrome 无头在受限沙箱里起不来 | `mojo platform_channel` 创建命名管道被拒（0x5），且 crashpad 也无法启动 | 提权到完全访问；已开着的浏览器则直接用 CDP 接管，不必再启动新的 |
| `--virtual-time-budget` 截图一直不结束 | 页面 rAF/定时器持续调度，虚拟时间预算走不完；即使脚本里把 `step` 换成空函数也一样 | 放弃虚拟时间，改 CDP：等 `document.title` 变成目标值后 `Page.captureScreenshot` |
| 游戏画面出现一块矩形暗带 | 星云贴图是 512×512，径向渐变的圆被画布边缘裁切，留下带 alpha 的硬边，放大后就是矩形接缝 | 生成贴图后用 `destination-in` + 径向渐变把边缘淡出到 0 |
| 木桩实测 DPS 只有设计值 1/3 | 子弹击退把木桩推出射程，后段子弹全部空放 | 模拟中每帧把木桩坐标钉住并清零 `kx/ky` |
| god 模式跑到 699 秒仍只有 2 个 BOSS | BOSS 移速 52、玩家 232，玩家一直风筝，BOSS 永远进不了射程；BOSS 存活还会压低刷怪，经验断供 | BOSS 提速到 96–118，并在距离 > 640 时"撕裂空间"闪现到玩家附近；模拟里同时看 `enemies` 是否长期顶到上限 |
| 玩家 10 分钟只有 20 多级 | 升级被摊到 4–5 把低级武器上，DPS 不足 → 清不动怪 → 经验少 → 更弱 | 用模拟对比"3 武器专注 / 平均铺开"两种选卡策略，把结论写进攻略提示 |
