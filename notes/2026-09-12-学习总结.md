## 2. winToolBox / Minisoft Toolbox 取证方法论（PUP 判定）

### 2.1 判定 PUP 的铁律
**绝不要凭「它在 AppData 里、名字可疑、带 Intercept/ScrCapture 模块」就下结论手删。**
先反查注册表 Uninstall 键：
- `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\` 与 `Wow6432Node\`
- 若查到完整 `DisplayName` / `UninstallString` / `Installer` → 走**官方卸载器**，绝不手删文件

本次反查发现：注册表 `DisplayName = "Minisoft Toolbox"`、`Publisher = "Minisoft Toolbox"`、
`Installer = "囧次元_102_10105732.exe"`、`InstallTime = 2025-08-24`。
→ 结论：这是「囧次元」动漫 App **捆绑安装**的推广软件（PUP），不是被篡改的木马。

### 2.2 取证要点（比原清单严重得多）
- **自启服务不是 1 个，是 5 个** LocalSystem 服务：
  `WinToolBoxUpdateSrv` / `WinInterceptUpdateSrv` / `CClearUpdateSrv` / `pdfReaderUpdateSrv` / `KaoZipUpdateSrv`
- **文件关联劫持是三层**：
  1. `HKCU\Software\Classes\.<ext>` 默认值 → `ZipMaster.*`（用户级）
  2. `HKCU\...\FileExts\<ext>\UserChoice` → 指向 ZipMaster ProgId
  3. `HKLM\SOFTWARE\Classes\.<ext>` 默认值 → `ZipMaster.*`（**机器级**，安装时提权改的，共 17 个扩展名）
  - 合计 **130 个 `ZipMaster.*` ProgId**，覆盖 `.rar .zip .iso .7z .tar .gz` 等 30 个扩展名
- **签名有效 ≠ 无害**：全部 exe 数字签名均为「北京奥兰德」正规企业证书（Valid）。
  这是「正规公司做的流氓软件」，不是病毒 —— 但仍是该卸载的 PUP。
- **注册表「乱码」是误报**：用 `winreg` 直接读时某些值显示为二进制乱码，实际是读取编码问题，
  真实字符串正常（DisplayName 等可读）。

### 2.3 处置流程（三阶段，全可逆）
1. `step1`：停 5 个服务 + 结束相关进程（管理员）
2. `step2`：手动跑官方卸载器 `unist00.exe`（交互界面，用户确认）
3. `step3`：清残留注册表 + 文件关联（动手前递归导出 `.reg` 备份，可一键回滚）
- **配套还原**：卸完 ZipMaster 后那 30 个扩展名会变「无关联」，需打开 WinRAR → 选项 →
  设置 → 集成 → 关联 → 全选（这步无法可靠程序化，交给 WinRAR 自己注册）。

## 3. SHFileOperationW 的坑（删除走回收站时）

| # | 现象 | 正确做法 |
|---|------|----------|
| 1 | 成功时也可能返回 `rc=2`（应为 0） | **判成败只看「文件是否真的消失」**，绝不看返回码 |
| 2 | 加 `FOF_SILENT`(0x0004) / `FOF_NOERRORUI`(0x0400) 后，在**中文路径**下返回 `rc=120` 且**静默不删**（最易被误判成「删好了」） | 只用 `FOF_ALLOWUNDO\|FOF_NOCONFIRMATION`（即 `0x0040\|0x0010`） |
| 3 | `pFrom` 必须以**双 null** 结尾，否则只删第一项 | `"\0".join(paths) + "\0\0"` |
| - | x64 下 `SHFILEOPSTRUCTW` = **56 字节** | `ctypes.sizeof()` 自检 |

> 推论：所有「删除」交付脚本统一用 `(0x0040\|0x0010)`，并以文件消失为准。

## 4. C 盘只读约束下的「可逆交付」模式

- 我**不动 C 盘**：删除类操作生成 Python 脚本放到 E 盘，由用户双击/命令行运行。
- 删除统一走**回收站**（`FOF_ALLOWUNDO`），保证可还原。
- 高风险写注册表（如修 AntiCheatExpert 的 `DisplayIcon`）前，脚本先**导出整个键为 `.reg` 备份**。
- **所有决策点用选项形式给用户选**（AskUserQuestion），不替用户拍板破坏性操作。

## 6. 工具链坑（本机实测）

- `sc.exe` 在黑名单里，不能用来查/停服务 → 改用 `ctypes` 调 `advapi32` / PowerShell。
- **`powershell.exe` 不能从 bash 工具里调**（stdout 不回显、易卡）；要用专门的 PowerShell 工具。
- Python 普通字符串里 `\\U`（如 `\\Uninstall`）会触发 unicode 转义错误 → 文档字符串也要 `r` 前缀。
- 本机有**「安全删除」拦截层**：`os.remove` 会被改道 trash 且中文路径失败 → 改用 Win32
  `SHFileOperationW` 回收站接口直接处理。
- 读 Windows 用户级环境变量用
  `[Environment]::GetEnvironmentVariable('NAME','User')`（从注册表读，不受进程继承影响）。
