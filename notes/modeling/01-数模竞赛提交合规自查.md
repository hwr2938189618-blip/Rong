# 数模竞赛 提交合规自查：内容做得再好，文件名错一样出局

> **日期**: 2026-11-28

> **状态**: 🟢 已整理

## 我要解决什么问题

数模竞赛（本次是 2026 APMCM C 题）里，论文内容、复跑证据都做完了，但**提交物本身的合规**是另一套规则，而且罚则极重——「不合规视为违反规则、无条件取消资格」。想在交卷前用一套可复用的清单把这类低级错误一次性扫干净，也想知道哪些「看起来不对」的地方其实官方模板本身就那样、根本不用改。

## 核心概念

**三层规则，来源不同、优先级不同，必须分开读：**

| 层 | 文件 | 管什么 |
|---|---|---|
| 参赛规则 | `参赛规则`（组委会红头，中文） | 赛程、报名、评审原则、纪律、摘要页与个人信息 |
| 提交规范 | `Essay format and submission specifications`（英文，2 页） | 命名、页数、字号、页眉、参考文献格式、附录要求 |
| 专项规定 | 《人工智能工具使用规定》（赛氪通知，单独发文） | AI 能用到什么程度、怎么标注、要交什么附件 |

只看中文参赛规则会漏掉英文件里的硬指标（命名规则、25 页上限、参考文献格式）；只看英文件会漏掉中文里的纪律条款（禁止思路交流群、个人信息泄露封顶成功参赛奖）。

**几条最容易踩的硬指标：**

1. **文件名就是合规项**：论文 `#***.pdf`（题号+队号，如 `Capmcm26309642.pdf`）、承诺书 `#***cns.pdf|jpg`、支撑材料 `#***fj.zip|rar`。带任何中文后缀（`_队内复核`、`_待签`）都不合规。
2. **承诺书必须每名队员手写签名**（英文名），缺签全队取消资格——这一项 AI 替不了，只能人工打印-签名-扫描。
3. **正文（含参考文献）≤25 页，附录不限**；页数要按「正文最后一页剩余空行」算预算，不是按总页数。
4. **摘要页第一页、目录页第二页、正文页码从 1 开始**；页眉只放队号和页码。
5. **摘要页与正文都不许出现学校/姓名**，出现一次就封顶成功参赛奖。
6. **正文与图表不许有中文**（支撑材料里的中文说明文件不受限）。
7. **参考文献必须用 `[ID] 作者, 题名[M/J], 出处, 年, 卷, 起止页` 格式，且正文里要真的引用到**——挂着不引用的条目是形式缺陷。
8. **AI 使用规定是独立一层**：核心模型构建/算法设计与求解/结果分析必须队伍独立完成；用 AI 就要在正文相应位置标注、在参考文献列出 `[编号] 名称, 版本/型号, 机构, 日期`、另交《AI工具使用详情》PDF（文件名就固定叫这个），内容要含「工具与版本 / 用途与环节 / 关键交互记录 / 采纳与人工修改」。

**「要不要改」的判据：拿官方模板自己编译一次对比。** 本次发现正文实测 10.5pt，低于英文规范写的「通常 11 或 12」，本来准备当缺陷报；结果编译/量测官方模板自带的 `main.pdf`，正文也是 10.5pt（中文 ctex 下 `\normalsize` 映射到五号）。官方自己的模板就长这样，说明 10.5 是模板默认、不是队伍偏离；反过来若改成 11/12，会直接把正文顶过 25 页上限。**结论：不动。**

## 踩坑记录

| 问题 | 原因 | 解决 |
|---|---|---|
| 审计脚本把「文件名不合规」判错成 `Apmcm26309642.pdf` | 队号首字母被当成了题号（`TEAM[0].upper()`），实际前缀是**题号** `C` + 队号 | 前缀单独取题号（问题选择的 A/B/C/D），别从队号里抠 |
| 字号审计误报「正文 6.5pt」（FAIL） | 附录源码 `lstset` 用 `\scriptsize`，字符数把正文淹了 | 只统计正文页（前 25–30 页），附录特例排除 |
| 独立复算的配对 bootstrap 上界 0.612，论文 0.604 | 我只跑了 2000 次重抽样，论文跑 1 万次 | 蒙特卡洛区间要标注抽样次数；差别在误差内就别当错 |
| 以为跨环境复跑能逐字节一致 | Q1 分类用 sklearn，1.8.0 → 1.9.1 会让准确率动 1–1.5 个点、macro-F1 动更多 | 「逐字节一致」必须锁定环境；跨环境只保证结论方向 |
| 中文路径/文件名一出现就紧张 | 规范只约束**正文与图表**不得有中文 | 支撑材料里的中文说明文件不违规，别乱改名 |
| `m.saikr.com` 用 web_fetch/read_page 抓不到 | 域名解析到 198.18.0.x（代理网段），工具拒绝非公网 IP；modsearch 模块缺失 | 用 Python `requests` 直连（带移动端 UA）即可，返回 200 |
